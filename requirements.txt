# Прямые зависимости проекта. Версии зафиксированы для воспроизводимости,
# все — актуальные на момент написания (проверено через `pip index versions`).
#
# neat-python 2.0.0 требует пары правок в конфиге, которых не было в 0.92 -
# они уже внесены в car_racer/config/config-feedforward.txt:
#   - добавлен обязательный параметр no_fitness_termination
#   - activation_options приведён в соответствие с activation_default (tanh)

#

# pymunk.pygame_util - проверено вручную, что весь API, который использует
# car_racer/cars/physic_car.py (Vec2d/.rotated()/.normalized(), Body, Space,
# Poly, DrawOptions), по-прежнему работает как раньше.
#
# shapely убран: сенсоры машин раньше считали пересечение лучей со стенами
# через shapely.LineString (самое дорогое место в тике обучения - создание

# машину). Заменено на ручной векторизованный (numpy) рейкастинг в

# понадобились: geometry полотна трассы вытащена напрямую из <path> без
